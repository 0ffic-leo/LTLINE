# LTLINE SOP-006 — Warranty and After-Sales

**Document ID:** LTLINE-SOP-006  
**Revision:** 1.0  
**Status:** DRAFT  
**Owner:** Service / Management

## 1. Purpose

Standardize customer support after delivery or project handover.

## 2. Service Intake

Register:

- Customer
- Product / project
- Installation date
- Complaint / request
- Symptoms
- Photographs or evidence where available
- Warranty status
- Urgency

## 3. Classification

Requests may be classified as:

- Warranty investigation
- Paid service
- Installation issue
- Product issue
- User / operating issue
- Spare-parts request
- Information request

## 4. Diagnosis

Review available documentation, installation conditions and operating history. Do not promise warranty coverage before the responsible assessment is complete.

## 5. Resolution

Possible outcomes include remote guidance, site inspection, repair, replacement, adjustment, spare parts, manufacturer escalation or quotation for paid work.

## 6. Closure

Record the action taken, materials used, labour where applicable, customer confirmation and any follow-up required.

## 7. Warranty Traceability

Warranty claims should remain linked to the original quotation, project, product and supplier/manufacturer documentation where applicable.
