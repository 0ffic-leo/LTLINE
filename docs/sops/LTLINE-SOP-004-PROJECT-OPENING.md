# LTLINE SOP-004 — Project Opening

**Document ID:** LTLINE-SOP-004  
**Revision:** 1.0  
**Status:** DRAFT  
**Owner:** Project Management

## 1. Purpose

Create a controlled project record before execution begins.

## 2. Opening Requirements

Confirm:

- Project code
- Customer
- Site / location
- Approved quotation / contract
- Scope
- Exclusions
- Technical requirements
- Drawings / documents
- Budget
- Schedule
- Procurement requirements
- Responsible personnel
- Safety requirements
- Handover requirements

## 3. Kick-Off

The responsible project owner communicates the approved scope, key risks, schedule, responsibilities and documentation requirements to the execution team.

## 4. Changes

Changes after project opening must be recorded and assessed for cost, schedule, technical and warranty impact.

## 5. Output

An active project file containing the approved baseline and project register entry.
