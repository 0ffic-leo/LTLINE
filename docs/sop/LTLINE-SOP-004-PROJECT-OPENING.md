# LTLINE SOP-004 — Project Opening

**ID:** LTLINE-SOP-004 | **Revision:** 1.0 | **Status:** DRAFT

## Procedure
1. Confirm signed/approved commercial scope.
2. Assign project code and project owner.
3. Create project folder and register customer/site data.
4. Review technical requirements and exclusions.
5. Establish budget and baseline schedule.
6. Identify procurement and subcontractor requirements.
7. Confirm site access, safety and required approvals.
8. Establish communication and reporting method.
9. Conduct kickoff review.
10. Release project for execution.

## Gate
Execution must not begin on the assumption that unresolved commercial or technical issues will be fixed later when those issues could affect cost, safety or performance.

## Records
Project opening form, approved quotation/order, scope, drawings/specifications, schedule, budget and kickoff record.
