# LTLINE SOP-005 — Installation and Commissioning

**ID:** LTLINE-SOP-005 | **Revision:** 1.0 | **Status:** DRAFT

## Procedure
1. Confirm latest approved technical information.
2. Verify materials and tools before installation.
3. Conduct site safety check.
4. Install according to approved scope and manufacturer instructions.
5. Record deviations and changes.
6. Perform visual and dimensional checks where relevant.
7. Perform electrical/mechanical/functional tests applicable to the system.
8. Correct defects and repeat tests where necessary.
9. Record commissioning results.
10. Prepare customer handover documentation.

## Safety
Only competent personnel should perform specialized electrical, HVAC, lifting, work-at-height or other regulated/high-risk activities as required by applicable rules.

## Records
Daily/site records, installation checklist, test results, commissioning record, photographs and handover pack.
