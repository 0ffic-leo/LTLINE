# LTLINE — Procesi i Ofertës

## Rrjedha

**Kërkesa → Mbledhja e të dhënave → Vlerësimi teknik → Kalkulimi → Shqyrtimi → Miratimi → Oferta → Ndjekja → Porosia**

## Kontrolli i ofertës

Para dërgimit verifikohen scope-i, sasitë, çmimet, afati i vlefshmërisë, kushtet e pagesës, dorëzimi, garancia dhe përjashtimet.

Çdo supozim teknik ose komercial që mund të ndikojë në çmim duhet të jetë i identifikueshëm.

## Statuset

`E RE` → `NË PËRGATITJE` → `NË SHQYRTIM` → `DËRGUAR` → `E PRANUAR` / `E REFUZUAR` / `E SKADUAR`
