# LTLINE — Dokumentacioni Zyrtar në Shqip

Ky është hyrja kryesore në dokumentacionin shqiptar të LTLINE.

## Struktura

- `INDEX.md` — indeksi qendror
- `sop/` — procedurat standarde të punës
- `forms/` — formularët dhe modelet operative
- `registers/` — regjistrat e kontrollit
- `00–10` — dokumentet themelore të sistemit

## Parimi i kontrollit

Dokumentet me status `MIRATUAR` janë versionet operative. Dokumentet `PROJEKT` janë ende në zhvillim dhe nuk duhet të konsiderohen kërkesa përfundimtare të kompanisë.

## Informacion i papërcaktuar

Kur një informacion real i kompanisë nuk është dhënë ende, përdoret `TBD` dhe nuk krijohen të dhëna të supozuara.
