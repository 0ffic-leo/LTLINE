# LTLINE — Shitje dhe Prokurim

**ID:** LTLINE-DOC-07  
**Revizioni:** 1.0  
**Statusi:** PROJEKT

## Procesi i shitjes

**Kërkesë → Kualifikim → Vlerësim teknik → Kalkulim → Ofertë → Negocim → Porosi → Dorëzim/Instalim → Dorëzim përfundimtar → Shërbim pas shitjes.**

## Oferta

Oferta duhet të përmbajë klientin, numrin dhe datën, vlefshmërinë, fushën e furnizimit, përshkrimin teknik, sasitë, çmimet, tatimet kur aplikohen, afatet, përjashtimet, garancinë dhe kushtet e pagesës.

## Prokurimi

**Nevojë → Kërkesë ofertash → Krahasim → Miratim → Porosi → Dorëzim → Kontroll → Pranim → Pagesë.**

## Vlerësimi i furnitorëve

Vlerësohen cilësia, përputhshmëria teknike, çmimi, afati, garancia, dokumentacioni, kushtet e pagesës, transporti dhe performanca e mëparshme.

## Kontrolli

Zëvendësimi i një produkti/furnitori që mund të ndikojë në specifikim, performancë ose garanci kërkon rishikim teknik dhe komercial.
