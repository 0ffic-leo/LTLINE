# LTLINE — Lista e Gatishmërisë për Eksport

## Para tregut

- [ ] Tregu i synuar është përcaktuar.
- [ ] Kërkesat ligjore dhe teknike të tregut janë verifikuar.
- [ ] Klasifikimi doganor / HS është verifikuar.
- [ ] Taksat dhe detyrimet e importit janë vlerësuar.
- [ ] Dokumentacioni i produktit është kompletuar.
- [ ] Etiketimi dhe paketimi janë verifikuar.
- [ ] Kushtet e garancisë janë përcaktuar.
- [ ] Transporti dhe Incoterms janë përcaktuar kur përdoren.
- [ ] Dokumentet e eksportit janë identifikuar.
- [ ] Çmimi i eksportit është kalkuluar.
