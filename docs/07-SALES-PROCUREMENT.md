# LTLINE Sales and Procurement Framework

**Document ID:** LTLINE-DOC-07  
**Revision:** 1.0  
**Status:** DRAFT

## 1. Sales Process

The standard sales flow is:

**Enquiry → Qualification → Technical Assessment → Costing → Quotation → Negotiation → Order Confirmation → Delivery / Installation → Handover → After-Sales**

## 2. Customer Qualification

Before preparing a significant quotation, collect enough information to understand:

- Customer identity
- Project location
- Required product / solution
- Quantities
- Technical requirements
- Required delivery date
- Installation requirements
- Site constraints
- Commercial expectations

## 3. Quotation Requirements

A controlled quotation should clearly identify:

- Customer
- Quotation number
- Date and validity
- Scope of supply
- Technical description
- Quantities and units
- Unit prices
- Taxes where applicable
- Delivery terms
- Installation scope where applicable
- Exclusions
- Warranty terms
- Payment terms

## 4. Discount Control

Discounts should be approved according to defined authority levels. A discount must not reduce the project below the approved commercial margin without explicit authorization.

## 5. Procurement Process

**Requirement → Supplier Search → RFQ → Comparison → Approval → Purchase Order → Delivery → Inspection → Acceptance → Payment**

## 6. Supplier Evaluation

Suppliers should be evaluated using relevant criteria such as:

- Product quality
- Technical compliance
- Price
- Lead time
- Reliability
- Warranty
- Documentation
- Payment terms
- Transport capability
- Previous performance

## 7. Purchase Order

Purchase orders should contain enough information to prevent ambiguity, including supplier, item/model, quantity, agreed price, delivery requirements, documentation requirements and applicable commercial terms.

## 8. Incoming Goods

Received goods should be checked against the purchase order and available supplier documentation. Material discrepancies, visible damage or specification mismatches should be recorded before acceptance where practical.

## 9. Supplier Performance

Important supplier relationships should be reviewed periodically using actual performance rather than price alone.

## 10. Commercial Records

Sales and procurement records should remain traceable to the related customer, supplier, project and transaction whenever possible.
